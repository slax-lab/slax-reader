## Review and acceptance

- The draft preparation review found that URL normalization could hide a readable bookmark, Labs rejections lost their recovery link, and a failed processing row disabled retry. The shared save-time URL policy now preserves a readable exact match and falls back to a readable normalized match. The native Chromium fixture verified the localized Labs message and Settings navigation, as well as a failed processing result followed by a successful retry. The full Web and API suites passed 3,488 and 4,586 tests. After these fixes, 18 Web bridge tests and 31 API URL and Labs tests passed, along with the Extension suite and the affected type checks.
- During a retry, the bridge can briefly return the preceding failed snapshot after a new acknowledgement. The popup may show the save action again until updated state arrives. The API admits a new attempt only for a failed bookmark row.
- The quick subagent review identified the root Inbox alias, foreground revisit, stale subscription click, and existing online PDF fallback contract. The changes accept both Inbox paths, capture a fresh visible visit, acknowledge the exact displayed watermark, and document recoverable versus unavailable source injection.
- Claude Opus 5.5 independently reviewed boundary cases. The changes bind the Save action to its initiating tab and navigation, reconnect popup sessions after worker disconnect, and clean up listeners during close and account transitions. The existing sync handler accepts the monotonic update as an idempotent no-op and the saved bookmark UUID matches the reader route identifier.
- The device clock supplies the browser-local cutoff and late-synced older saves remain subject to the browser-visible snapshot boundary. The real deployed PowerSync stream, OTP/sign-in with a live account, native Alt+Y keystroke, and automatic service-worker idle suspension were not exercised. The smoke tests use isolated local fixtures and do not access production user data.
