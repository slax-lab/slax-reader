圆角 & 阴影

圆角在墨水屏模式下自动收紧（14→4px, 10→2px），阴影在墨水屏模式下禁用。

--radius
14px / 4px(eink)
大圆角 · 文章卡片、图片、悬浮按钮（FAB）、弹出菜单、面板等较大尺寸的容器
--radius-sm
10px / 2px(eink)
小圆角 · 按钮、侧栏导航项、工具栏槽位、输入框、tag、徽章等较小的交互元素
--shadow-warm
暖色主阴影 · 用于 FAB、底部工具栏、边缘工具栏、弹出菜单、文章卡片 hover 等所有「漂浮在内容之上」的元素，墨水屏模式下自动禁用
--shadow-sm
轻量阴影 · 预留 token，用于轻量提示性悬浮（如输入框 focus、小型 toast），目前主要页面尚未使用

桌面态三档布局逻辑

Free 临界 = content_w(820) + 2 × panel_w + 2 × buffer(40)
Push 临界 = content_min_w(640) + panel_w

模式触发条件行为
Free 居中视口 ≥ Free 临界内容居中，面板贴右，无重叠
Push 左推Free 临界 > 视口 > Push 临界内容向左推（push = 面板宽），可阅读宽度 ≥ min
Push + 软覆盖视口 ≤ Push 临界push 卡在 视口 − min，面板自然重叠到文字右侧
