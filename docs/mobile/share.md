# Native inbound sharing

`plugins/with-share.cjs` generates the standalone iOS `SlaxShare` app-extension target and Android incoming `com.slax.reader.extension.ShareActivity`. It is app-owned build code and introduces no share package. Run it through Expo prebuild; do not hand-edit generated Xcode/Gradle projects.

The plugin requires the public `apiBaseUrl` and accepts `apiBetaUrl`, `versionName`, and `versionCode`. The standalone iOS extension has no Firebase configuration input. The extension selects the beta endpoint only when persisted `selected_env` is `BETA`, matching the original application. Production and beta settings are written to each native entry's configuration. Missing configuration stops generation. HTTP development endpoints add extension ATS permission and must be restricted to an authorized development build.

## iOS

The app extension retains identity `app.slax.reader.share` and App Group `group.app.slax.reader`. It uses its own UIKit controller and URLSession and does not start React Native, the main application, or PowerSync. The source 180-point panel, collection spinner, success checkmark, spring animations, haptic response, error text and outside-tap dismissal are retained. Safari preprocessing provides the document title and URL; as in the source, document HTML is not uploaded. The extension sends `target_url` and optional `target_title` to `/v1/bookmark/add_url`.

Safari webpage activation and preprocessing are declared together. The reader uses Apple's [property-list type](https://developer.apple.com/documentation/uniformtypeidentifiers/uttype-swift.struct/propertylist) through `UTType.propertyList.identifier`; the installed SDK reports `com.apple.property-list`. The legacy literal `public.property-list` does not identify that payload. The preprocessing URL supplies the fallback when Safari has no separate `public.url` attachment, while an explicit URL attachment retains precedence. Only absolute HTTP/HTTPS preprocessing URLs with a host are accepted, and their exact text is preserved. Native acceptance must verify both the actual webpage title and URL against the controlled server, rather than a sender-provided subject.

The plugin creates target source/resource phases, embeds the `.appex` in the main target, adds App Group entitlements and inherits the main target's signing team/style when present. Configurations retain iOS 16.4, matching the approved floor. The human must retain the original signing/extension provisioning identities for an actual upgrade. By explicit user decision, the standalone extension does not import, initialize, link or report through Firebase. Repeated prebuild removes its former owned Pod block and Firebase resource membership while preserving the main app's resources and telemetry. Run CocoaPods after generation to reconcile linkage. Operator configuration files are not read or deleted by this removal; an unreferenced old generated file does not enter a fresh extension bundle.

## Android

The local `slax-share` module supplies a translucent native activity and source-sized collecting/success/error card. The generated main manifest registers ACTION_SEND with CATEGORY_DEFAULT and `text/plain`. It consumes `EXTRA_TEXT` and `EXTRA_SUBJECT`, validates the source's leading-URL format, and saves directly through HttpURLConnection without mounting the React app or opening its database. Success dismisses after two seconds; outside dismissal and activity destruction close the request lease before disconnecting, so a delayed worker cannot attach a request after teardown. The source activity identity is retained. Firebase reporting uses the approved application's already-linked native Analytics class when present.

## Shared authentication

Both entries take `.slax-preferences.lock` before reading `slax.preferences.v1.json`. Android additionally serializes same-process readers/writers using the canonical lock-path monitor to avoid overlapping FileChannel locks. The new JSON's values contain `auth_token` and `selected_env`. If it exists without an auth token, the entry remains signed out; it cannot resurrect the old session.

Before the first main-app migration, the entry can read the original `user.preferences_pb` string fields directly, without editing that file. Corrupt data produces the source's safe collection failure message. The extension never mutates authentication on HTTP 401, matching the source's standalone share client. Redirects are refused so bearer credentials remain with the configured API origin. No token, preference content or underlying network exception is printed.
