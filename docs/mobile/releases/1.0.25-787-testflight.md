# TestFlight delivery: 1.0.25 (787)

## Authorization and source

This build follows the owner's hands-on review of build 786 on 2026-10-24. The Library list scrolling fix was accepted. Two new issues were reported: the Reader back button jumped when the Reader opened, and offline-cached articles took a long time to show.

The owner asked for another TestFlight build, without pushing code. The build is `1.0.25 (787)`, with previous bound `786`. It comes from the uncommitted branch `feat/mobile-native-smoothness` and adds:

- **Header:** the Reader route's navigation-bar options are static from the first frame (transparent, fixed trailing slot).
- **Cached reads:** they run on a foreground native queue and start concurrently with the record lookup.
- **iOS host:** it mounts immediately, behind the cover.
- **Prewarm:** the Reader module is preloaded, and the iOS WebKit is prewarmed once the Library is presented.
- **Fade:** the cover fades in 120 ms.

No commit, push, pull request or API deployment is part of this delivery.
