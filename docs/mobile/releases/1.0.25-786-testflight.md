# TestFlight delivery: 1.0.25 (786)

## Authorization and source

This build follows the owner's hands-on review of build 785 on 2026-10-23. The owner found that Library scrolling still jittered and dropped frames, and asked for another TestFlight build without pushing code. The version stays `1.0.25`; the build is `786`, with previous bound `785`. The source is the same uncommitted branch `feat/mobile-native-smoothness`, plus these Library scroll fixes:

- **Row layout:** `getItemLayout` counts each row's separator, so virtualization spacers match the rendered rows.
- **List:** `FeedList` is React Native's plain `FlatList`, so cells no longer get an extra per-cell animated wrapper.
- **Rows at rest:** they write no shared values on mount and use one animated style. Swipe buttons and the title-flash overlay mount only while needed.
- **Updates while scrolling:** Library row updates are held during a scroll and applied once it settles.
- **Header:** the list header is memoized.

No commit, push, pull request or API deployment is part of this delivery.
