# TestFlight delivery: 1.0.25 (789)

## Authorization and source

This build follows the owner's hands-on review of build 788 on 2026-10-26, which raised four Reader issues:

1. The outline and overview animations were missing.
2. Outline Markdown rendered incorrectly.
3. The back button did not hide and show with the More button.
4. A transparent strip appeared at the top on iOS Liquid Glass.

The owner asked for another TestFlight build and did not ask for the code to be pushed. The build is `1.0.25 (789)`, previous bound `788`, built from the uncommitted branch `feat/mobile-native-smoothness`. Changes in this build:

- **Outline and overview motion:** the outline's Markdown view mounts only after its motion settles. KMP's skeleton, dots and ring loaders are ported, and the overview dialog grows from its excerpt.
- **Outline Markdown:** now rendered by `markdown-it` 15.0.2 with `markdown-it-cjk-friendly` 3.0.0. These are the versions already resolved for the Web app; the frozen install passes.
- **Back button:** the native Reader header is replaced by a KMP-style navigator bar. Back and More hide together; swipe-back and system back are kept.
- **iOS 26 scroll-edge effects:** hidden on the Reader route and on the Reader's own scroll view.

No commit, push, pull request or API deployment is part of this delivery.
