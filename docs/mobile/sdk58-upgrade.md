- Android min/compile/target SDK: 26/37/36. R8 remains enabled for Release. Signing generation/admission share an owned guard that handles both Gradle assignment spellings and rejects stale template debug signing even when an owned marker exists.
- Android uses SDK 58's packaged Expo core native libraries by default. The Debug build executes `decompressPrebuiltNativeLibs` and its CMake cache supplies `EXPO_PREBUILT_NATIVE_LIBS_DIR`; no core source-build override is enabled. CMake still compiles the Worklets integration, Expo Modules V2 and third-party native modules (including SQLite, Nitro, Reanimated and Screens). A task named `expo-modules-core:buildCMakeDebug` alone does not mean the prebuilt core was bypassed. The first Debug validation uses the template's four ABIs; subsequent local Release validation uses `-PreactNativeArchitectures=arm64-v8a` to avoid unnecessary host/legacy architecture work. This is a validation command, not a change to distributed architecture support. See the [SDK 58 prebuilt-core announcement](https://expo.dev/changelog/sdk-58).
- iOS deployment floor remains 16.4. The generated SceneDelegate starts React Native; Expo forwards scene links to the existing Google subscriber. Main-app Firebase insertion supports the new scene template and fails on missing insertion points. Configured-main native Firebase acceptance remains pending; standalone Share stays Firebase-free.
- Strict RN instance/ref types are enabled. TypeScript's global `node`/`react` types are declared explicitly; no legacy deep-import condition, broad error suppression or dependency patch was added. WebView's default generic is instantiated with `unknown` to retain its declared props rather than the package's `Props & undefined` default.
- The human approved source metadata `1.0.25 (774)`, with `previousBuildNumber: 773`, for the current delivery. The previous bound comes from the latest `origin/dev` source metadata; it is not independently verified store publication history. Existing native generators must keep Android and iOS main/Share/widget metadata consistent. This decision does not authorize signing, upload or publication.
