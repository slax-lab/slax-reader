### Optional user guide: system actions and service features

These notes describe how to use the features; they are not PR acceptance checkboxes or merge prerequisites. The human owns any hands-on/account/service exploration. An unavailable simulator system application or account is a limitation of that attempt, not a failed product test or an invitation to bypass admission.

On the authorized Duo simulator, first check which Siri/Shortcuts and Spotlight interfaces the installed runtime actually exposes. If a Shortcuts interface is available, choose the compiled Slax Reader save action and supply a required HTTP(S) URL and optional title. Otherwise record that invocation was unavailable in this runtime; opening the app, inspecting metadata, or a web search for Shortcuts does not constitute a Siri/Shortcuts test. Spotlight exploration requires iOS 18+, admitted account data and eligible catalog entries. Searching the OS and opening a matching title can exercise that simulator's route, while OS indexing/suggestion timing is not guaranteed by a JavaScript callback. These observations are distinct from the CI controller tests and do not certify service-backed end-to-end behavior.

- **Siri/Shortcuts save:** Invoke “Save a link in Slax Reader” or “Save to Slax Reader” with a required HTTP(S) URL and optional title. Every new invocation remains unclaimed until you explicitly choose **Claim and save**, even when the app is already signed in and running. For a cold or signed-out start, complete Login and wait for current account/data/credentials to be ready first, then claim the queued link. Claim binds it to that ready account and starts saving through the existing API; the bookmark appears only after successful saving. If offline or saving fails, restore connectivity and use **Retry**. Native handoff or app launch does not mean the link was saved.
- **System search and suggestions:** Sign in, open the Library drawer’s **Settings** page, confirm the desired default-on controls (or retain explicit opt-outs), and on iOS 18+ search for a recent eligible bookmark in Spotlight. Open it and verify it resolves in the currently admitted account. Turn the options off and confirm removal/retry behavior in the app; do not rely on OS metadata as authorization.
- **IAP:** Sign in, open **Library drawer → Subscription**, then use the configured sandbox store account to complete a purchase, cancel a purchase, and restore purchases. Verify entitlement state after each result and that cancellation does not grant entitlement.
