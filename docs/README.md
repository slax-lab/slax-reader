# docs

Documentation for the Slax Reader monorepo.

## What belongs here

- Documentation for contributors: how to set up the workspace, build, test, and run each app.
- Architecture notes that span more than one app or package.
- Migration and layout notes for the monorepo itself.

## What does not belong here

- Per-app user documentation that already ships with its own code — keep it next to that code unless there is a reason to consolidate it here.
- Internal planning material. This repository is public: do not put internal roadmaps, schedules, or non-public planning details in `docs/`, or anywhere else in the repository.

## Migration source

New — no existing repository migrates into this directory. Note that `slax-lab/slax-reader-cli` currently carries its own `docs/` for CLI usage; whether that content moves here is a migration-time decision.
